# 莱茵实验室视觉与模型交互重设计

桌面实现已打包至 release/desktop/win-unpacked/Rhine Lab.exe。请保留整个 win-unpacked 文件夹运行。

## 已实现

- 独立模型检视来源，首次打开主机先检视，手动进入终端；返回保留 SSH 会话。
- 底部中央拆解／重组，九组外壳与内胆沿装配轴展开，实测最小层间距为模型宽度 6%。
- 原版旋转、缩放、平移与复位；连续反向保留弹簧位置和速度；重组后交接至原生字号终端。
- 移除终端拆解工具、入场扫描线与重复背景纹理；未恢复未读提醒。
- 统一总览、终端、设置与菜单材质及尺寸；总览支持拖动、位置记忆和双击归位。
- 保留全部十套主题 ID，以语义化颜色统一亮暗表面、输入、焦点和边界；设置共用五分类导航。
- 网页原版查看器保持默认调用，安卓保持原连接入口与工具排列。

TypeScript、桌面打包、网页与 Android 资源构建通过。最终打包应用的 18 项原生冒烟检查全部通过（含启动、WebGL、桥接、总览快捷键及标题栏主题），见 native-smoke.json。总览拖动回归、9 项会话单元检查、主题插值检查及模拟 Android 导航检查通过。

检视覆盖 800×600、1366×768、1920×1080（2× DPI）、2560×1440；工具栏额外覆盖 800×600 与 1024×640。检查包含手动进入、连接不抢视角、失败回退、减少动态效果、真实鼠标旋转与滚轮缩放、键盘平移、双会话认证隔离、八会话缓冲保留、剪贴板、文件编辑、传输与监控。

10 套主题 × 明暗模式的设置文字／语义化次级文字至少 4.5:1，控件边界／焦点至少 3:1。此项不是逐像素全页面对比度审计。

同机 Edge 无头环境、同画质、1920×1080 下，以当前原版档案检视器为对照，持续平移各取两次 180 帧：原版与终端检视 P95 均约 4.3ms，比值 1.00。此结果为 requestAnimationFrame 帧间隔，不是独立 GPU 时间；不代表不同显卡或 Android 实机结果。详见 performance.json。
