# 桌面 SSH 工作区

2026-09-15 新增字体／字号／字距／行距、项目与 tmux、重连、双终端、文本编辑、转发、监控提醒、参数化命令和配置迁移，完整操作见 [工作区设置与项目档案](SSH-WORKSPACE-SETTINGS.md)。电脑默认字号 13px、范围 8–32px；此项覆盖下文早期版本的字号范围。

通过 `npm run dev:desktop` 启动开发版，或先执行 `npm run build:desktop`，再执行 `npm run start:desktop`。需要 Windows 系统 OpenSSH；网页与 Wallpaper Engine 版本不提供 SSH。

首次桌面构建会下载并校验固定版本的 Go 工具链，生成本机 SSH 桥接程序和 Linux 采集器。之后仅在源码或校验值变化时重新构建，不要求远端安装 Go、Python 或 Node。构建和依赖说明见 [SSH 服务源码](../services/ssh/README.md)。

## 主机总览

桌面版默认打开半透明磨砂总览，背后保留原来的玻璃档案阵列。五条物理阵列承载主机和可编辑的快捷档案，命令、目录收藏、历史和密钥库放在总览的页签中。原网页和壁纸继续使用原资料内容；安卓使用同一套 SSH 界面，见 [安卓版](ANDROID.md)。

| 入口 | 内容 |
| --- | --- |
| 主机 `H-` | 保存的主机和 SSH config 别名、连接状态与实时占用。`Ctrl+Shift+S` 返回总览。 |
| 会话标签 `S-` | 总览和终端顶部均显示本次运行的连接及保留输出，点击切换，× 结束并关闭该标签。 |
| 目录收藏 | 直接打开原会话的远端路径，或连接对应主机后打开；终端内仍有完整 SFTP 与传输队列。 |
| 命令 `C-` | 本机保存的常用命令，可新建、编辑、移除，选择明确的 `S-` 会话后插入。 |
| 历史 `R-` | 已结束连接的记录、事件与导出，支持清理过期记录。 |
| 密钥库 | 本机私钥文件引用、加密导入、类型／指纹／关联主机与移除。 |
| 快捷档案 `A-` | 可编辑名称、主机、目录和正文，读取后打开终端、SFTP 目录、监控或运维笔记。 |

总览可检索名称、地址、用户与档案编号。悬停或键盘聚焦一台主机约 100ms 后，背后的阵列会用约 750ms 动画定位；连续移动会接续当前运动，只在最终位置选档，不会自动连接经过的主机。点击主机连接，已有连接时返回该主机最近使用的活跃会话；行末“详情”可先查看这台主机，＋ 另开连接，“编辑”打开配置。

点击右上的“收起”或按 `Ctrl+Shift+H` 可收起总览。原来的档案编号、主机说明、读取按钮、滚轮、列／档案导航和设置继续可用；顶部边缘标签或“主机总览”可重新展开，收起偏好会保留到下次启动。

滚轮或拖动选到主机后，点击已选中的模型可读取详情；也可按住选中模型向上抽出，达到约四成高度后松手进入详情，短拉或向下放回会归位。其余位置拖动仍自由浏览阵列，鼠标和触摸共用逻辑。有会话的主机还会显示“打开终端”，可从阵列直接放大已有终端。

SSH 阵列关闭空闲呼吸及流量引起的起伏，保留选档波浪、悬停、抽取和归位。不会再因终端持续输出而自行上下抖动。

## 快捷档案

在总览“快捷档案”中创建卡片，可选择终端、远端目录、主机监控或运维笔记。名称、正文、关联主机及目录均可编辑，保存后同步到三维阵列，仍按原动画抽取、显示。可以关闭自动打开，先读取说明再连接。

远端目录卡直接进入指定主机的 SFTP 目录；终端卡填写绝对目录时，每次新建独立标签，成功连接后自动切换到该目录。目录按 POSIX shell 规则转义，正文只显示，不作为命令执行。监控卡打开主机监控，笔记卡无需连接。档案保存在本机，不自动同步到其他设备。

## 保存与连接

- **新增主机**：点击总览“添加主机”，选择“保存主机”，填写名称与地址，按回车保存，或选择“保存并连接”。
- **临时连接**：在同一页切换到“临时连接”，填写地址后按回车或点击连接。名称可选，本次参数不会自动保存。
- **编辑主机**：点击该行的“编辑”。改名保留原来的档案编号和会话关联。
- **SSH config**：读取本机配置中的主机别名。该主机的“连接配置”页可保存为新主机档案，继续继承原别名的 SSH 选项；表单中填写的参数用于覆盖默认值。
- **移除主机**：在“连接配置”页再次点击“移除此主机”确认。当前档案移除后回到目录，原会话记录保留，系统 SSH config 不变。

支持同时运行多个独立会话。普通连接会返回同一主机已有的活动会话；主机详情的“新开会话”会另建连接，即使目标主机相同也有独立的 `S-` 编号。修改或移除主机前须结束该主机的所有活动会话。输入错误、保存冲突或写入失败时会显示原因并保留已填内容。后台刷新不会重建正在编辑的输入框，切换页签后也可继续原草稿；草稿只在本次运行中保留。保存遇到配置版本冲突时，可选择“重新读取配置（放弃此草稿）”载入最新值，再继续编辑。

## 连接选项

| 字段 | 用法 |
| --- | --- |
| 主机地址 | 主机名、IPv4、IPv6 或系统 SSH 配置别名；也可填写 `user@host`。端口使用单独的端口栏。 |
| 用户名 | 留空沿用系统 SSH 的解析结果。 |
| 端口 | 1–65535，新连接预填 22；清空后使用系统 SSH 配置。 |
| 登录方式 | 自动、密码、密钥。自动沿用系统 SSH 选择；密码优先使用密码认证；密钥模式只使用公钥与服务器额外验证，不静默改用账户密码。 |
| 登录密钥 | 从共享密钥库选择，或点击“选择本机私钥”添加文件引用。已有配置也可继续使用高级选项中的私钥路径。 |
| 跳板机 | `[用户@]主机[:端口]` 或 SSH 配置别名；多个跳板机用英文逗号分隔，IPv6 带方括号。对应 `ProxyJump`。 |
| 连接超时 | 1–600 秒，新连接预填 10 秒。 |
| 保活间隔 | 0–3600 秒，新连接预填 30 秒；0 关闭 SSH 保活消息。 |
| 保活重试次数 | 1–30，新连接预填 3；连续无响应时由系统 SSH 判定连接断开。 |

展开“连接选项”可填写跳板机、超时与保活；选项可清空以使用系统 SSH 配置。主机密钥确认仍使用实际指纹提示与系统 known_hosts。

### 保存密码与密钥

在主机配置中勾选保存凭据并输入密码或私钥口令，保存后会显示“凭据已加密保存”，不会把秘密回填到输入框。也可在实际认证提示中选择记住；这种情况下只在认证成功后保存。重新连接和彻底重启应用后均可自动使用，不需要另设主密码。主机先保存成功、凭据保存失败时会保留同一主机和本次输入，修正后重试不会创建重复主机。

凭据由 Windows 当前账户加密，独立保存在 `ssh-credentials.json`，不写入主机配置、网页本地存储或事件日志。自动复用必须匹配目标、实际主机、端口、用户、密钥和已验证的主机指纹；主连接成功后的凭据可用于同目标的 SFTP 和监控。每个连接只自动尝试一次，失效后改为手动输入并标记需要更新。验证码和服务器的交互式额外验证不自动填入密码。

密钥库支持 OpenSSH / PEM 私钥的**本机文件引用**和**粘贴导入**，同一密钥可关联多台主机。文件引用保留原文件；原文件变化或被移走后需要重新选择。粘贴导入的内容会加密保存，只在连接期间生成当前账户可访问的临时文件，最后一个使用者退出后删除，异常退出的残留在下次启动清理。PuTTY PPK 需先转换为 OpenSSH 格式；本版不生成密钥。

“清除保存凭据”会让下次连接重新询问。移除密钥前先解除关联主机并结束仍使用它的连接；移除文件引用不会删除原私钥文件。切离编辑页面会清空秘密字段，普通连接草稿仍可保留。

认证页面位于原档案详情的位置，标题滚动、细线展开、字段与操作依次进入，左侧包装盒继续展示实际鉴权输出。动画期间即可输入，重复状态更新不会清空或重新聚焦输入框。主机目录、配置、历史和完整记录使用同一组页面动效；启用“减少动态效果”时直接显示。

## 操作与重连

已保存及 SSH config 主机都有各自的档案卡，沿用原包装盒和标签，在盒内显示当前鉴权信息；进入交互会话后，开盒与镜头拉近同步开始，以先慢后快的节奏放大终端。临时连接同样可从会话标签返回其终端。

终端内胆使用 Blender MCP 制作的无边框显示层：整面屏幕覆盖背板，仅保留细角标与状态灯。操作态扩大到可用视口附近，文字仍为原生像素。保留 2.1 秒同步拆盒与拉近、1.2 秒重组；桌面“拆解终端”可以查看光导、显示、散热、主板和背板五层，再一键重组。

操作页顶部的横向标签和 `Ctrl+Tab` / `Ctrl+Shift+Tab` 可切换连接，标签可横向滚动，也支持方向键、Home 和 End。已展开终端之间使用约 180ms 淡入与短提示音，保留展开的包装和镜头；各连接保留自己的终端缓冲、目录、侧栏与监控采样。后台认证在会话状态中提示，切换到对应会话才显示输入页。密码、文件认证与命令都绑定具体会话，不能因切换而转发到另一台主机。

右上角的“收起 · 返回主机”或 `Ctrl+Shift+E` 会收盒并退回当前主机详情，连接、终端缓冲和后台输出继续保留。在详情点击“打开这次会话”或点击左侧模型，即可再次放大；详情左上角返回进入主机阵列／总览。`Ctrl+Shift+T` 也可打开所选主机已有的终端。旁边的设置可在放大终端上直接打开，关闭后回到当前终端。终端内的 `Esc`、`Tab` 和方向键仍发送给远端。

标签上的 × 结束并移除该会话；关闭后台标签不会切走当前终端。最后一个标签关闭时，终端画面完成收盒后再释放资源，总览保留所有主机与历史。在总览关闭标签也不会自动打开别的终端。

会话结束后保留输出，终端顶部显示“重新连接”。快速连接复用本次输入的完整参数；保存的主机按当前保存配置重新连接，仍正常进行主机验证和认证。再次启动应用后，已保存主机仍在列表中；临时快速连接不会自动保存。

有未完成传输时，“结束会话”先在原位提示影响并等待确认；退出应用会提示仍在运行的会话和传输。重载或窗口关闭会清理其原生连接，保留历史和原始事件日志。无法取得渲染端完整审计时，宿主保留仅包含实测字节、时长与退出状态的记录，不补造鉴权事实。

命令库的“插入到终端”不会补回车，执行前由你确认；多行命令要求远端程序启用 bracketed paste。没有可输入的活动会话时，插入入口停用。库中的命令按纯文本保存，不作为启动脚本自动运行。

## 终端搜索与常用操作

点击终端原页脚右侧的 **终端操作**，或在输出上点击右键，操作区会在同一个页脚内展开。沿用页面细线、暖灰／暗色配色与错峰进入动效，退出后归还终端空间；减少动态效果时直接切换。

| 操作 | 用法 |
| --- | --- |
| 查找输出 | `Ctrl+Shift+F` 聚焦搜索。查找当前终端及最多 5000 行回滚输出，支持中文与自动折行文字；`Aa` 切换区分大小写。 |
| 上一项／下一项 | 点击 ↑／↓，或在搜索框中按 `Shift+Enter`／`Enter`。新输出会更新结果；全屏程序中查找当前屏幕缓冲区。 |
| 复制 | 在终端内拖选文字，再用“复制选中”或 `Ctrl+Shift+C`；搜索选中的匹配文字也可复制。 |
| 粘贴 | “粘贴”或 `Ctrl+Shift+V` 将剪贴板文本送入当前终端，不额外补回车，支持远端程序启用的 bracketed paste。 |
| 字号 | `A−`／`A+` 或数字输入框在 10–24px 之间调整，点击数值按钮恢复默认 13px（安卓为 12px）。仅调整终端文字，自动更新远端行列数；重连和下次启动保留字号，已有手动设置不覆盖。 |
| 收起操作区 | `Ctrl+Shift+P` 切换展开／收起；操作区内按 `Esc` 或点击“返回输入”收起并聚焦终端。 |

终端输入中的普通 `Ctrl+C`、`Ctrl+F`、`Esc`、`Tab` 和方向键仍发送到远端。复制／粘贴快捷键在搜索框里只作用于该输入框。`Ctrl+Shift+E` 继续收起整个终端并重组包装盒。

搜索词只保留在当前会话内，重新连接时清空。断线后仍可搜索和复制保留的输出，粘贴入口停用。剪贴板只在用户执行复制／粘贴时访问；如果读取期间收起终端、切换焦点或重新连接，该次粘贴取消。超过 1 MiB 的文本会显示原因，不截取一部分发送。

功能与桌面终端验证见 [终端工具验证](../verification/SSH-TERMINAL-TOOLS.md)。

## 同页文件与监控

终端顶部原有细线导航增加 **终端、文件、监控**。默认在终端右侧显示 SFTP 文件；选择监控后原位置显示主机指标，选择终端后收起侧栏。分隔线可拖动，或聚焦后用方向键调整，侧栏宽度为 260–480px，默认 320px。宽度不足以同时容纳侧栏和约 80 列终端时，三个页签在同一容器内切换；切换、收起和重开均保留同一个终端缓冲区。

放大窗口会增加真实终端行列数，文字按窗口的实际像素密度绘制。操作态不继承整页缩放或三维透视，按钮、拖选、侧栏和远端鼠标协议共用相同坐标。1920×1080 下操作面约 1704×907，比原来的 1339×713 增加约 62% 面积。原包装盒、标签、终端厚度仍由三维模型呈现，开盒与镜头仍同步使用 2.1 秒、先慢后快的动画；上方品牌收拢，为工作区留出空间。字号仍可独立设为 12–24。

### SFTP 文件

- 地址栏可直接输入路径；返回上级、主目录、刷新、名称过滤、排序和隐藏文件开关放在文件页内。大目录分批读取并只渲染当前可见行。
- “收藏目录”将当前主机和远端路径保存到总览的“目录收藏”，各会话的当前路径独立保留。
- 双击文件夹进入；点击选中，Ctrl 多选、Shift 连选，方向键和 Enter 可操作列表。文件属性显示大小、修改时间、权限及链接目标。
- 上传文件或文件夹使用原生选择窗口，也可将本地文件拖入文件页。下载可选择多个文件或目录，再选择本地保存目录。
- 新建目录、重命名和删除使用原位输入或确认；删除文件夹包含其内部内容。删除符号链接只删除链接本身。
- 文件类型用克制的颜色和类型标识区分；输入中的路径、名称和远端文本均按文本展示。

页脚 **传输** 展开当前会话队列，最多同时运行两个任务，显示进度、速度、文件数和跳过项。同名目标可选择跳过、覆盖或保留两份，也可应用于本次任务的后续冲突。取消和失败后可重试；重试从头读取，不提供断点续传。递归传输跳过符号链接和特殊文件，单个目录任务最多 100000 项。

上传与下载先写临时文件，再提交到目标位置。异常中断若留下不能自动恢复的文件，会显示恢复路径；结果无法确定时要求先核查，避免自动重复覆盖。网络完全阻塞时，取消可能需要等待文件通道结束；重新连接文件通道会中断该通道上的传输。应用退出不持久化传输队列。

### 主机监控

主连接认证成功后自动建立辅助 SSH 通道并准备采集器。沿用系统 SSH config、密钥和跳板机，按上述目标绑定规则复用已保存或本次确认成功的密码／口令；辅助通道需要独立验证时仍使用原页面的认证动效，并标明 SFTP 或监控来源。验证码每次独立询问。

| 指标 | 更新与展示 |
| --- | --- |
| CPU、内存、Swap、负载 | 每秒更新 CPU 占用、核心数、1/5/15 分钟负载、内存和交换分区。 |
| 网络与磁盘 I/O | 根据相邻采样计数计算真实读写、收发速率，按网卡区分。 |
| 文件系统容量 | 每 10 秒读取挂载点的总量、已用和可用空间。 |
| NVIDIA | 持续运行 `nvidia-smi -q -x -l 1`，每秒读取多卡利用率、显存、温度、功率、风扇及可见进程。 |
| 历史 | 当前会话保留最近 300 个采样点，约五分钟；断线保留最后读数并明确标记停止。 |

GPU 先显示设备总览，点击可跳到对应设备详情；进程列表默认折叠。占用数值使用 180ms 滚动和固定单位，高 GPU 利用率以琥珀表示，故障另有明确状态。超过三秒没有更新会标记陈旧；不可用的指标显示缺失状态，不伪装为零。没有 NVIDIA、驱动工具缺失或部分权限不足时，CPU 等其余指标仍可使用。监控页支持重新启动采集，文件页也可独立重连。

采集器当前支持 Linux amd64/arm64，以登录用户权限运行，缓存于 `$XDG_CACHE_HOME/rhine-lab/monitor/<版本>-<哈希>/`；未设置时使用 `~/.cache`。上传前后校验 SHA-256，匹配缓存直接复用。不会使用 sudo、监听端口或安装常驻系统服务。断开时关闭子进程；心跳每五秒发送，连续十五秒没有心跳或标准输入结束时，远端采集器会退出并结束其 `nvidia-smi` 子进程。缓存文件保留供下次连接使用，断开后可手动移除该缓存目录。

远端需要允许 SFTP、执行用户缓存目录中的程序，以及使用 `sh` / `uname` 识别系统。只读或 noexec 缓存、禁用子系统及非 Linux 主机将显示具体不可用状态，终端仍可使用。GPU 进程信息受服务器权限和驱动支持限制。

实现与真实服务器、原生协议、窗口坐标验证见 [SSH 工作区验证](../verification/SSH-WORKSPACE.md)。

## 本地数据

应用保存的连接位于 Electron 用户数据目录的 `ssh-hosts.json`，系统主机来源为 `%USERPROFILE%/.ssh/config`。应用最多保存 256 台主机，均可从总览访问并分布在五条物理阵列中。移除后的 `H-` 编号不会分配给新的主机。原版本主机配置可直接读取，密码与密钥使用独立的加密凭据库。

会话记录位于同一用户数据目录的 `ssh-logs/`，保留策略仍为 30 天、最多 200 个会话和 64 MiB，活动会话豁免。主机详情中的“会话记录”显示该主机的历史；目录中的同名页签显示全部历史，移除主机后仍可在这里查看和导出，并可清理过期记录。旧记录显示连接当时的主机名称。

目录收藏、命令、功能卡编号与各主机的侧栏宽度和页签保存在本机 `rhine.ssh.workspace`，当前数据版本为 1。无法识别的版本和损坏的数据会保留原值并提示；它们不会被空数据覆盖。重启后不恢复活动连接、传输队列或未执行的命令，也不自动重连。

## 动效、声音与运行开销

开盒保持 2.1 秒二次加速，与镜头拉近同时进行；重组约 1.2 秒。关闭或换选中的归位卡保留它自己的终端画面和标签，不再出现原资料内构。认证、配置、库与编辑页沿用原页面动效，减少动态效果时直接切换。

终端操作期间，被覆盖的三维场景在稳定后暂停绘制，窗口尺寸、主题变化和关闭时恢复；盒内纹理只在内容变化时更新，最多每秒 15 次。隐藏会话继续解析终端协议和接收监控数据，停止绘制隐藏图表和重复 fit。

桌面配色在原细线、玻璃与标签之上使用骨白／蓝石墨、冷青灰与香槟琥珀。实体运动仍用玻璃音色，终端重开、收起、结束会话与切换标签有各自的短提示，遵循现有声音开关和音量，重复状态不重复播放。需要认证、连接成功、意外断开、批量传输结果仍有对应提示；输入、输出与逐秒指标保持安静。操作态的背景音乐平滑降至所设音量的 45%，收起后恢复，不修改保存的音量和开关。

大范围滚动会复用可见性计算缓冲，把已落回阵列的细微归位运动并入现有批次，并裁剪离屏归位模型。保持当前画质、阴影和动效；实际测量与新版总览、凭据、重启和 DPI 验证见 [SSH 总览验证](../verification/SSH-OVERVIEW.md)。

实现、画面及本地测试范围见 [主机档案列与页面动效验证](../verification/SSH-ARCHIVE-UI.md)。
