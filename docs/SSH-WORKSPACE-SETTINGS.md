# SSH 工作区设置与项目档案

2026-09-15，电脑与安卓共用此套功能。总览或放大终端右上的「设置」打开工作区设置，「画面与声音」继续进入原来的设置页。

## 终端排版

「终端操作」和「设置 → 终端文字」均可调整，所有会话实时共用同一份偏好。

| 设置 | 默认与范围 |
| --- | --- |
| 字体 | 默认 JetBrains Mono；另有 IBM Plex Mono、系统等宽。前两种字体的 Latin 常规／粗体随应用打包。 |
| 字号 | 安卓 11px、电脑 13px；8–32px，步长 0.5px。此前手动设置的字号继续保留。 |
| 字距 | 默认 0px；−1～3px，步长 0.1px。负值收紧字符，过小可能重叠。 |
| 行距 | 默认 1.15 倍；1～2 倍。 |

终端字体列表移除了比例字体 MiSans，修正安卓固定字符格中视觉字距过大的问题；界面正文仍使用原字体。字体载入后重新计算行列数，盒内预览使用当前终端的字体和字符步进。排版保存于 `rhine.ssh.terminal-appearance`，未知版本不会被覆盖。

## 项目与快捷档案

总览「快捷档案 → 新建」可选择项目工作区、终端、远端目录、主机监控、端口转发或运维笔记。所有类型沿用原档案卡、抽取与开盒动画。

- 项目保存主机、绝对目录、tmux 名称、侧栏页签／宽度、第二终端主机和正文。再次读取复用该项目仍活动的会话；重新连接后在真正进入交互态时恢复目录和命名 tmux。远端需使用兼容的 POSIX shell；tmux 不存在时提示并保留普通 shell，不自动安装。
- 电脑终端顶部「分屏」选择活动会话或新连接。拖动分隔条调整比例，松手后保存；也支持方向键与 Home／End。第二终端可收起，连接仍在标签中。可用宽度不足 960px 或安卓上使用标签切换，项目中配置的第二连接仍可通过标签访问。
- 正文按纯文本显示，不当作命令执行。终端目录卡继续新建独立会话，避免改变其他会话的当前工作。tmux 名称只允许字母、数字、下划线和连字符。
- 分组、置顶、组内上移／下移同步更新总览与物理档案顺序，编号保持稳定。

「档案开启动画」默认每次完整开盒。可改为当前应用运行期间首次完整、之后约 0.6 秒展开；首次仍使用原来的 2.1 秒同步开盒拉近，关闭仍约 1.2 秒。减少动态效果设置继续优先简化动画。

## 恢复连接与状态提醒

默认只对曾经进入交互态、随后异常中断的会话自动重连，最多五次。等待从 2 秒增加到最多 30 秒，离线时等待网络恢复。手动结束、认证拒绝、主机指纹变化或点击「停止」终止重试；设置可关闭恢复或改为 1–20 次。

自动恢复的是 SSH 连接。项目配置了 tmux 时重新附着到命名会话；普通 shell 不能恢复已退出的远端进程，也不重放此前输入的命令。应用重新启动后仍需手动打开连接。

默认 CPU ≥95%、磁盘 ≥90%、GPU 温度 ≥85°C 持续 30 秒后提醒；断线持续 8 秒后提醒。阈值、持续时间和开关均可设置。过期采样不参加计算，同一状态只提醒一次，恢复后重新计时。提醒通过应用内消息与静态标记显示。总览与标签显示连接状态、未读输出、活动传输数和提醒，不以模型运动表示流量。

## 安卓后台与跳板机

「安卓后台保持连接」默认关闭。开启后使用 connectedDevice 前台服务与持续通知，提供「返回终端」「全部断开」。Android 13 及以上请求通知权限；通知被拒绝时可在系统应用设置中开启。

服务持有原生进程和唤醒锁。连接全部结束后保留最多十分钟的恢复窗口，通知显示等待恢复；新连接恢复活动通知。关闭开关、通知中全部断开、应用任务移除或有意重载释放服务／旧连接。系统强制停止、回收或厂商省电仍可能中断连接；命名 tmux 用于保留远端工作。

主机编辑的高级选项可选择已保存的跳板机，最多三层，禁止循环。每一层独立确认指纹和认证，目标主机的状态不会由中间节点代替。首跳使用 Android DNS，后续目标通过前一跳连接。SFTP、监控和转发复用最终已认证 transport。活动路由中的跳板机不能被编辑或移除。

## SFTP 文本编辑

普通文件「打开」、双击或 Enter 可读取 UTF-8 文本，最大 1 MiB。支持 JavaScript／TypeScript、JSON、Python、Shell、YAML 高亮，Ctrl+S 保存，比较当前修改或重新读取远端对照。二进制、超大文件和符号链接不进入文本编辑器。

内容与元数据形成版本摘要，保存时及提交前重新核对。冲突显示远端对照和本地草稿，用户核对并再次保存才更新。先写同目录临时文件、保留权限，再使用原子重命名或原有备份／回滚提交。SFTP 没有通用的比较并交换协议，最终提交仍存在极短的并发窗口；提交后再次读取确认，异常时显示恢复路径。

草稿仅保留在所属会话内存中，最多 32 份未保存草稿；保存／采用远端版本释放位置。重连后需读取远端确认；移出会话或关闭应用清理草稿。

## 端口转发

创建「端口转发」档案，填写主机、目标地址／端口、本地端口（0 自动分配）。开档并完成 SSH 连接后建立监听；「设置 → 端口转发管理」复制本地地址、查看活动 TCP 数或关闭。

只监听 `127.0.0.1`，每会话最多 16 个转发，每转发最多 16 条 TCP 连接。SSH 会话结束时关闭监听与数据连接；自动重连不重建已关闭转发，需要重新开档。监听成功不等于目标服务已验证，访问本地端口时才建立远端通道，失败显示原因。

安卓复用已认证 transport 的 direct-tcpip。电脑每条 TCP 连接使用受管理的 `ssh -W` 子进程，沿用系统 SSH 配置和认证，不创建远端 shell。不提供 SOCKS 或远端端口转发。

## 检索与命令

总览／终端「检索」或 Ctrl+Shift+K 搜索主机、档案名称／分组／正文、目录、命令与会话；方向键选择，Enter 打开，Esc 返回。

命令支持 `{{name}}`、`{{name=默认值}}`。参数输入后显示完整预览，值按 POSIX shell 单词转义，占位符不要再包引号。选择明确目标后才插入，不添加回车，仍由用户执行；多行片段继续要求 bracketed paste。

## 配置迁移

设置底部导出 JSON，包含主机元数据、档案、目录、命令、排版与偏好。默认不含密码和私钥。勾选加密凭据后需设置至少 8 字符备份密码，只有密文进入文件。

AES-256-GCM 使用独立随机盐与 IV、PBKDF2-SHA256 210000 次及固定格式 AAD。电脑主进程读取、加密凭据，明文不返回 renderer；安卓经既有 Keystore 桥接读取后生成兼容封装。备份密码不保存。解密预览票据只保留十分钟，关闭设置即取消。

导入依次选择文件、检查内容／解密、点击导入。合并主机与档案，重映射目录、分屏和跳板引用；冲突档案另存，原主机不被改写。不含私钥的备份需要先在目标设备导入相同指纹的私钥，或改用含加密凭据的备份。首次 SSH 指纹仍需确认，导入不会自动信任主机或连接；后台服务开关保留本机值。

系统 SSH 别名需能解析出实际主机、用户和端口。ProxyCommand 不改写为直连；依赖系统配置私钥路径的主机应先保存为档案并关联密钥库。电脑的自动认证导入安卓时映射为已关联私钥或密码认证；需要验证码的主机可改为交互认证。电脑导入的跳板链转换为系统 SSH 明确地址，中间节点认证沿用本机配置或连接时输入，不能假定安卓私钥绑定会替代电脑系统配置。

导入是分步骤合并；磁盘或密钥库出错时报告已新增主机数，已导入内容保留，可修正后重试。活动连接、传输队列、未执行命令和草稿不在备份内。
