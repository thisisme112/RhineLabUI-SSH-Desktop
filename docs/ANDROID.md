# 安卓 SSH 工作区

安卓版使用与电脑端相同的档案阵列、开档连接动画、会话标签、终端、文件与监控界面。主页面只包含 SSH 主机和用户创建的快捷档案，原资料内容保留在网页与壁纸版本。

## 安装与构建

```sh
npm run android:build          # Android renderer、原生 SSH 服务、同步与 debug APK
npm run android:sync           # 只构建 renderer 并同步 Capacitor 工程
npm run build:android-native   # 编译、校验并放置 SSH 代理与 Linux 采集器
npm run android:apk            # 已同步资源后，仅执行 Gradle assembleDebug
npm run build:android-assets   # 从项目共享标志生成启动器图标与启动画面
```

APK：`android/app/build/outputs/apk/debug/app-debug.apk`。包名仍为 `cc.lubeiluchen.rhine`，版本为 1.0.2（versionCode 10002）；Android 工程 minSdk 22、targetSdk / compileSdk 34，使用 Capacitor 6、JDK 17 和 Gradle 8.2.1。

安装同包名、同签名的新 APK 可保留已有主机、主机指纹和加密凭据。不要卸载旧版或清除应用数据后再更新。当前提供 debug 签名包；尚未配置正式发行签名。

`scripts/android-build.mjs` 优先使用 `JAVA_HOME` / `ANDROID_HOME`，也支持本机已有工具链；不修改系统环境。临时目录下的工具链可能被系统清理，长期构建建议设置常驻 JDK 17 和 Android SDK。`android/local.properties`、生成的网页、JNI 代理及监控二进制均不进入 Git。

安卓版有独立的 Vite `android` 模式和 `dist-android/` 目录，Capacitor 使用原来的本地 HTTPS 来源。应用资源随 APK 离线打包，不注册 PWA Service Worker。网页和壁纸不启用 SSH，电脑端不调用安卓插件。

## 主机与会话

在主机总览添加主机，填写地址、端口、用户名及登录方式。支持密码、导入私钥和服务器交互式认证；安卓的“交互式认证”对应 keyboard-interactive。首次连接显示真实主机指纹，确认后才继续认证；已记住的主机密钥发生变化时拒绝连接。

主机总览和终端上方均有可横向滑动的会话标签。点击主机复用最近的活动会话，主机行的 ＋ 或“新开会话”建立独立连接，最多同时 12 个。每个会话有自己的终端缓冲、认证请求、文件目录、传输和监控数据。

总览收起后仍有档案说明、读取按钮和上下左右导航；已选中的模型可点击读取，也可向上抽出后松手读取。连接时先在原档案中显示真实鉴权，成功后使用原来的 2.1 秒同步拆盒和镜头拉近，进入终端操作区。SSH 阵列不再自动呼吸，也不随流量上下起伏；选档波浪、抽取与归位保留。

放大终端的“收起 · 返回主机”保留连接并回到主机详情，详情或会话标签可重新打开。系统返回键依次关闭设置、认证页、记录、放大终端和档案详情；返回到根页面时，仍有连接则把应用放到后台，没有连接才退出。结束连接使用会话标签上的 ×。

## 性能与画质

安卓首次启动使用 **“手机”画质预设**（关闭环境光遮蔽与景深，透射和阴影减半），在设置里自选任一预设或单项后不再自动套用；升级前保存过的默认画质也按此处理。帧率跟随画面：交互和动画时最高 60 帧，静止的主页降到 30 帧，全屏终端 / 门户页遮住场景后暂停三维渲染（`src/frame-budget.ts`）。连续掉帧时渲染分辨率自动在 100%–60% 之间逐级降低，稳定后缓慢回升，不会来回震荡。WebGL 画布关闭多重采样（画面本来就经后处理管线输出）。软键盘弹出 / 收起时三维缓冲只在动画结束后重建一次。安装包不再带未带哈希的重复模型文件。

## 手机操作

- 终端默认字号 **11px**，电脑端为 13px，范围 8–32px。“终端操作”和工作区设置均可调整字体、字号、字距和行距；**双指捏合**终端也可直接缩放字号（半号一档，同样写入这份外观设置）。采用随包提供的等宽字体，保留原有手动字号。
- 终端操作区使用可见视口的原生 CSS 像素，随软键盘和旋转调整行列数。文件、监控、主机表单和正文各自滚动，手指滑动正文不会拖动背后阵列。
- 在终端输出上上下滑动可读取回滚缓冲（松手后带惯性滑行）；全屏程序收到滚轮事件。底部按键条可左右滑动：键盘、Ctrl、Esc、Tab、方向键、Home / End / PgUp / PgDn、`| ~ / - _`、`^C` `^D`。方向键与翻页键按住会连发；方向键遵循程序设置的光标键模式（vim、tmux 等的应用模式）。Ctrl 轻点作用于下一个字符，**长按锁定**，再点解除。选择文字时把手指拖到终端上下边缘会自动滚动回滚缓冲并延伸选区。按键、锁定 Ctrl、连接成功 / 失败带轻触觉反馈（`localStorage["rhine-haptics"] = "off"` 关闭，系统“减少动效”时也不震动）。
- 文件列表轻点选中后，使用“打开”进入目录；也保留电脑端的双击和 Enter。上传通过手机文件／目录选择器，下载通过目录选择器保存，不要求整个存储空间权限。

## 可编辑的快捷档案

总览的“快捷档案”页可以创建、编辑和移除实体档案卡，卡片使用稳定 `A-` 编号，与主机一起出现在五条物理阵列中。

| 类型 | 读取后的行为 |
| --- | --- |
| 终端 | 打开关联主机；填写绝对目录时，每次新建独立会话，连接成功后自动 `cd` 到该目录。 |
| 项目工作区 | 恢复主机、目录、命名 tmux、侧栏和第二会话；手机通过标签切换。 |
| 远端目录 | 连接关联主机并打开指定的 SFTP 目录，可复用活动会话。 |
| 主机监控 | 连接并打开该主机的监控页。 |
| 运维笔记 | 按原动画抽取、展示用户正文，无需连接。 |
| 端口转发 | 连接后监听本机回环地址，经 SSH 转发到指定目标。 |

可编辑名称、关联主机、目录和纯文本正文，也可关闭“读取后自动连接并打开”，先读说明再手动打开。正文不会当作命令执行。目录必须以 `/` 开头，按 POSIX shell 规则转义；不改变其他标签的当前工作。支持分组、置顶、排序与 JSON 配置迁移，尚无自动云同步。

## 文件与监控

SFTP 支持目录浏览、上传／下载、目录传输、创建、重命名、删除、冲突处理、取消和重试，复用桌面 Go 服务实现。手机文件先经 Storage Access Framework 放入应用专属缓存；上传完成或会话结束后清理这份副本。下载完成后复制到用户选定的手机目录，保存失败保留缓存和重试入口。传输重试从头开始，不支持断点续传。

监控通过已认证连接建立独立通道，复用 Linux amd64 / arm64 用户级采集器，显示 CPU、内存、磁盘、网络以及可用的 NVIDIA GPU 指标。无需 sudo、额外监听端口或注册系统服务。远端需为受支持的 Linux，GPU 信息依赖服务器上的 `nvidia-smi`；不支持时显示实际原因，不生成模拟数据。

## 数据与原生实现

| 部件 | 位置与职责 |
| --- | --- |
| 共享 renderer 适配 | `src/ssh/android/bridge.ts`：提供会话、主机、凭据、文件、监控和记录接口；界面复用 `SshSessionBank`。 |
| SSH 协议代理 | `services/ssh/cmd/session`：使用 `golang.org/x/crypto/ssh`，通过 JSON-lines 发送真实协议阶段、认证提示和终端流。 |
| 原生会话插件 | `SshSessionPlugin.java`：每个会话独立进程和 token，处理 DNS、输入输出、键盘及生命周期。 |
| 文件选择与保存 | `SshDocumentsPlugin.java`：显式文件／目录选择器、缓存、导出和文本剪贴板。 |
| 凭据加密 | `SshVaultPlugin.java`：Android Keystore + AES-GCM；主机配置不包含明文秘密。 |
| 辅助通道 | `internal/native/authenticated.go`：复用本次已认证的 SSH transport，接入原 SFTP 与监控服务。 |

代理针对 arm64-v8a、armeabi-v7a 和 x86_64 编译，以 `librhine-session.so` 放入 JNI 目录。`useLegacyPackaging = true` 让安装器解包到 `nativeLibraryDir`，插件从该位置启动进程。构建过程核对二进制 SHA-256，采集器和依赖许可一并打包。

保留此前 `rhine-android-ssh-v1` 主机存储、原主机 ID 和 `rhine.ssh.credentials.v1` Keystore 别名，继续读取用户原有配置和密码。凭据绑定主机、端口、用户名、认证方法和实际主机指纹；OTP 不记住。私钥通过文件选择器导入并加密保存，不创建明文私钥临时文件。未知或损坏的主机、密钥和工作区存储保留原值并停止覆盖。

会话记录加密保存在本机，元数据用于历史列表，最多 100 个、保留 30 天。日志来自协议事实；终端输出中的文字不能改变可信连接状态。统计为终端 UTF-8 文本字节，不是网络总流量。

## 电脑上的排版与交互检查

不接手机也能复查：`npm run build:android` 后运行 `npm run check:android-layout`，用替身 Capacitor 桥在 Edge 里以 360×800 竖屏和 800×360 横屏截图（`verification/android-phone/`），并断言主机总览没有小于 36px 的点按目标、没有横向溢出、顶部操作没有被挤出屏幕；`npm run check:android-terminal` 覆盖输入法、按键条、Ctrl 锁定、连发、捏合、惯性滚动与选区边缘滚动。这些代替不了真机：软键盘、系统输入法、发热与帧率仍以手机实测为准。

## 当前边界与本轮记录

安卓已支持最多三层保存主机组成的跳板链和可选后台前台服务，仍不直接读取系统 OpenSSH config、ssh-agent、本机私钥路径或任意 SSH 参数。后台服务、恢复策略、SFTP 文本编辑、提醒与加密配置迁移见 [工作区设置与项目档案](SSH-WORKSPACE-SETTINGS.md)。

用户已实测确认之前的安卓单会话版本可连接。本次升级在其后完成，按用户“不用测试”的要求，仅做源码检查、类型检查、编译和打包，没有再次安装、操作手机，也没有对新版多会话、SFTP、监控和视觉做运行时验收。最新产物与变更记录见 [SSH 工作区与终端排版](../verification/SSH-WORKSPACE-SETTINGS.md)，前轮记录见 [SSH 档案与安卓升级](../verification/SSH-ARCHIVES-ANDROID.md)。
