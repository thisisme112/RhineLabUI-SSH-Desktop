# SSH 工作区与终端坐标验证

日期：2026-09-13。本轮仅修改桌面 SSH 及其共用场景内的 SSH 镜头分支，沿用原生 DOM/TypeScript/WAAPI、Three.js 和既有 Blender 资产。只做本地提交。

## 实现范围

- 终端与文件 / 监控使用同一容器，320px 默认侧栏、260–480px 拖动、紧凑页签和共享 xterm。
- SFTP 元数据、文件 / 目录上传下载、原生选择窗口和拖入、两路队列、冲突选择、取消 / 重试、临时提交与恢复路径。
- 系统 OpenSSH config、密钥、ProxyJump；主会话认证目标绑定，辅助认证绑定连接与指纹，OTP 独立询问。
- 连接后自动注入 Linux 用户级静态采集器，CPU / 内存 / 网络 / I/O 逐秒采集，文件系统每十秒，NVIDIA 持续逐秒、多卡及进程，五分钟历史与陈旧状态。
- 采集器无监听端口、无 sudo、无常驻注册；会话关闭和心跳失效回收子进程。二进制与许可的构建清单可校验。

## 放大模糊与鼠标错位修复

旧终端挂在按 1080 高度缩放的 `#stage` 中，同时通过 `matrix3d` 贴到三维屏幕。字体先栅格化再缩放，而 xterm 按未缩放的 CSS 单元尺寸解算鼠标，导致最大化、DPI 变化时拖选和远端鼠标行列偏移。

现在仅在操作态将同一个 xterm 挂在实际 `#viewport`，将当帧模型屏幕角点换算为视口 CSS 像素并取整，直接设置 left / top / width / height。终端及祖先没有缩放或透视，不再放大文字位图。三维动画仍由真实屏幕纹理表现，原外框、标签与厚度保留；仅拉近最终相机、收拢顶部品牌。1920×1080 下工作面从约 1339×713 提升到 1704×907，面积约增加 62%。窗口改变时重新 fit 真实 PTY 行列，而不是缩放旧终端。

模态栈仍按原 stage 管理：认证 / 记录覆盖时，视口终端保留 DOM 和缓冲但让出显示、输入与焦点；关闭覆盖层即恢复。2.1 秒同步开盒与拉近、二次加速、1.2 秒重组和中途反向规则保持。

[几何验证报告](ssh-workspace/geometry/report.json) 的真实 CDP 鼠标输入覆盖：

| 视口 | DPR |
| --- | --- |
| 1366×768 | 1 |
| 1920×1080 | 1、1.25 |
| 1600×900 | 1.5 |
| 2560×1440 | 1、2 |
| 3440×1440 | 1 |

每组验证完整祖先链无变换、16px 原生字号、面板边界、可见单元 (5,2)、(40,6)、(80,10) 的 SGR 按下 / 松开行列，以及拖选后复制恰好得到 `PIXEL_MATCH` 与 `中文选中`。另外验证侧栏随指针移动恰好 55 CSS px、认证和页签按钮真实命中、字号按钮、收起 / 重组 / 重开后的同一个 xterm。此 DPR 覆盖属于 Chromium 模拟，不等同于多台真实显示器实测。

## 实际远端服务器

通过用户指定的 SSH config 主机建立了真实 Electron / 系统 OpenSSH 会话，没有读取或记录密码。已观察到：

- 真实 SFTP 通道进入 ready，并返回登录用户主目录。
- Linux x86_64 采集器自动上传并执行，缓存包含版本和哈希；远端为 OpenSSH 7.4。
- 40 个 CPU 核心、约 503 GiB 物理内存总量、11 个文件系统、7 个网卡的真实数据。
- 四张 Tesla P100-PCIE-16GB 持续返回实际占用、显存、温度、功率和 GPU 进程；观察时三张繁忙、一张空闲，`gpuState=live`。
- 连续观察超过五分钟，采样序号达到 356，历史固定为 300 点。

这里证明真实 Linux 执行和真实 NVIDIA 采集；不是 fixture 画面。未把主机地址、账户、指纹、目录列表或密码写入提交中的验收附件。远端写入仅包括自动采集器缓存。

后续窗口已关闭，未在该主机完成独立验收目录内的手动上传 / 下载、缓存重启复用及进程消失观察。原生文件窗口自动化通道本轮不可用，因此不把这些列为真实服务器验收通过；相应文件协议、哈希、取消和进程退出覆盖来自下述隔离测试。

## 限制和诊断

- 实机运行验证为 Windows amd64 客户端和 Linux amd64 远端；Linux arm64 采集器已交叉编译，未实机运行。
- 当前为单 SSH 会话；传输任务不跨应用重启保留、不提供断点续传，递归传输跳过链接和特殊文件。
- 文件操作遵循服务器权限。完全阻塞的文件读写取消可能需要文件通道断开；元数据 RPC 超时会关闭文件通道，防止超时后继续悄悄修改。
- 没有 NVIDIA 或工具 / 权限不全时明确降级，读数缺失不当作零；不改变 GPU 工作负载。
- 并行运行两个图形验收时有一次 CDP 输入调用超时；单独重跑完整工作区通过。几何验收等待页签动画真正结束后再检查无变换，避免在 350ms 尾帧测量尚未结束的原生淡入位移。
- node-pty 在隔离测试快速结束时偶尔由独立 `conpty_console_list_agent.js` 打印 `AttachConsole failed`。测试通过，Electron 主进程没有退出后 resize 异常。Three.js / ANGLE 另有既有浮点精度警告，未当成无警告运行。
