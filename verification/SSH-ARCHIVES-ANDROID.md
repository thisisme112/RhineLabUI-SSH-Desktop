# SSH 无边框终端、快捷档案与安卓共用工作区

日期：2026-09-15。

用户已实测确认此前安卓单会话连接可用，随后明确要求“不用测试”。本记录对应之后新增的模型、档案和安卓共用界面，仅记录实现、源码检查与编译打包；没有对本版本重新运行自动测试、真实 SSH 连接、安装 APK 或操作手机。旧截图和旧报告不能用来证明这一版的视觉、文件、监控或并发功能已实机验收。

## 实现

### 屏幕与模型

- 使用 Blender MCP 执行 `art/build_terminal.py`，保存 `art/ssh-terminal.blend` 和 `src/ssh/assets/ssh-terminal.glb`。新 GLB 为 118960 字节，分为光导角标、显示、散热、主板、背板五个具名层。
- 显示层为 4.36 × 2.42，背板为 4.30 × 2.36，取消宽边框；角标线宽 0.012，保留微小状态灯。原档案外包装和标签继续复用，不改变抽取时的平面坐标。
- `terminal-deck-parts.ts` 只负责加载资产和更新材质／背光。真实终端纹理使用 glTF UV 方向，所有会话保持独立 xterm 缓冲和归位快照。
- 保留 2.1 秒、二次加速的拆盒与镜头同步，1.2 秒收回，以及五层拆解／重组。操作镜头按屏幕高度约 97.5%、宽度约 98.5% 的视口上限适配实际宽高比；安卓操作态使用整个可见视口。以上为代码参数，不是本轮截图测量值。
- 默认字号电脑 13px、安卓 12px，10–24px 可调，并提供直接输入；保留已有手动字号。降低行距和内部留白。

### 阵列与快捷档案

- SSH 场景不再启用空闲呼吸，并停止将 PTY 流量送入音乐位移。选档波浪、悬停、抽取、归位和自由平面拖动继续使用原逻辑。
- 主机和 `A-` 快捷档案共用五条物理阵列，总览新增“快捷档案”。支持终端、SFTP 目录、监控和笔记，名称、正文、关联主机、路径及自动打开均可编辑。
- 终端目录卡每次新建会话，在对应代次真正进入交互态后发送一次经过 POSIX 单引号转义的 `cd`。失败、取消或换代不会把目录命令发到其他连接。笔记只显示纯文本。
- `rhine.ssh.workspace` 继续使用 version 1，通过可选 `shortcuts` 字段兼容旧数据；校验路径、类型、长度和 ID 唯一性，损坏数据不覆盖。快捷档案的背景刷新保留编辑草稿及已有正文节点。

### 安卓

- 独立 Android Vite 构建连接 `src/ssh/android/bridge.ts`，共用主机总览、认证、开盒、会话标签、终端、文件和监控组件。停止使用此前独立的单会话工作区入口。
- 每会话独立 Go 代理，原生 token 隔离输入、认证、事件、尺寸与退出；最多 12 条连接。阶段事件直接来自 SSH 协议，不用终端文字伪装认证结果。
- SFTP 和监控复用本次已认证 SSH transport，调用现有 Go 服务；打包 Linux amd64 / arm64 采集器。手机文档通过 SAF 显式选择，上传副本在成功或会话结束后清理；下载保存失败保留重试路径。
- 保留 `rhine-android-ssh-v1`、原主机 ID、Keystore 别名及指纹绑定，继续读取此前保存的主机与密码。私钥加密保存；密钥和历史元数据逐项校验，未知格式停止写入。
- 紧凑手机布局、可横向滑动的会话标签、正文独立滚动、终端回滚、软键盘及 Ctrl / Esc / Tab / 方向键。文件列表增加明确“打开”动作，单击选中后即可进入目录。
- 系统返回逐层处理当前页面；根页面有活动连接时退到后台。系统回收或省电策略仍可能结束连接，本次未增加后台常驻服务。
